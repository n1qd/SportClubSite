# hypesport-web

Веб-приложение спортивного клуба на Next.js и React.

## Установка и запуск

```bash
cd hypesport-web
npm install
npm run dev
```

Приложение по умолчанию поднимается на `http://localhost:3000`.

## Git-репозиторий

Если хочешь версионировать **только** папку `hypesport-web`, инициализируй git здесь:

```bash
cd hypesport-web
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
git push -u origin main
```

Файл `.gitignore` уже настроен так, чтобы не попасть в репозиторий `node_modules`, сборки и `.env.local`.
